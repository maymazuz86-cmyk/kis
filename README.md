# הכיס שלי

אתר אישי למעקב הכנסות והוצאות: לוח בקרה, הוספת תנועות, ייבוא פירוטי אשראי ובנק (Excel / CSV / PDF), דוחות, תקציב ותובנות.

- כניסה עם חשבון Google, והנתונים נשמרים ב-Firebase Firestore (פרויקט `kis-money`) תחת `users/{uid}`.
- `firestore.rules` הם כללי האבטחה: כל משתמשת קוראת וכותבת רק את הנתונים שלה.
- האתר מתארח ב-GitHub Pages מתוך ענף `main`.
